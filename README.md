# The Ley Lab website

Static site for the Ley Lab (Section of Stem Cell Biology, Division of Oncology,
Washington University School of Medicine). Built by a small Python script — no
Jekyll, Ruby, or Node.

## Layout

```
build.py                 static-site generator (stdlib only, offline)
serve.sh                  build + preview at http://localhost:8000
update_publications.py    refresh the publication list from PubMed (needs network)
fetch_citations.py        refresh citation counts from OpenAlex (needs network)
src/
  site.json               lab identity, nav, socials, contact block, accent color
  data/
    team.txt              hand-edited roster (members + alumni) — see header comment
    pubmed_overrides.txt   hand-edited exclude / include / reclassify by PMID or DOI
    extra_publications.json  hand-curated records from the Scholar reconciliation (committed)
    publications.json      generated by update_publications.py (committed)
    citations.json         generated by fetch_citations.py (committed)
  pages/                   one .html per page: index, publications, team, 404
  partials/                _page shell, head, header, footer, sidebar, member
  assets/                  css/main.css, js/site.js, img/
build/                     output — deploy this (git-ignored)
```

## Everyday edits

- **Text on a page** — edit `src/pages/*.html`, then `python3 build.py`.
- **Team roster** — edit `src/data/team.txt` (format documented at the top of the
  file), then `python3 build.py`. Drop member photos in `src/assets/img/`. Each
  member with a `match` string gets an auto-generated `member-<name>.html` page
  listing that person's publications.  ##TODO - definitely a place to add more customization
- **Preview** — `./serve.sh` (or `python3 build.py --serve`).

## Updating publications

```
python3 update_publications.py --dry-run   # show what would change
python3 update_publications.py             # write src/data/publications.json
python3 build.py
```

`update_publications.py`:

1. runs a PubMed author search (`Ley TJ[Author]`) and fetches metadata for each hit;
2. asks **OpenAlex** for this author's `conference-abstract` and `erratum` works —
   the ASH / AACR / ASCO meeting abstracts PubMed doesn't index;
3. classifies every record as **publication / abstract / other** and writes
   `src/data/publications.json`.

Only *publications* show by default on the site; the **Abstracts** and **Other**
buttons on the Publications page reveal the rest, each tagged with a small label.

Corrections go in `src/data/pubmed_overrides.txt` (`<id>` = a PMID, or a bare DOI
for records with no PMID):

```
exclude 12345678                      # wrong "Ley TJ" — drop it
exclude 10.1158/1538-7445.am2015-169  # drop an abstract by DOI
include 23456789                      # PubMed missed it — add this PMID
kind 34567890 abstract                # force the type
```

### Reconciling against Google Scholar (one-off, ~yearly)

Scholar can't be scraped in the normal flow, but `scripts/` has a one-off pipeline
to compare against it:

```
python3 -m venv /tmp/scholar-venv && /tmp/scholar-venv/bin/pip install scholarly
/tmp/scholar-venv/bin/python scripts/verify_against_scholar.py    # scrape + write publications_unverified.md
#   review publications_unverified.md; record decisions for the "Other" bucket in
#   scripts/scholar_classification.tsv
python3 scripts/build_extra_publications.py                       # -> src/data/extra_publications.json
python3 scripts/verify_against_scholar.py                         # refresh publications_unverified.md
python3 update_publications.py && python3 build.py
```

`extra_publications.json` holds hand-curated records (mostly older meeting abstracts
and author corrections) that neither PubMed nor the OpenAlex sweep produces; it is
committed and merged by `update_publications.py`. `scripts/scholar_ignore.txt` is the
list of Scholar entries already handled or dismissed, so they stop showing in
`publications_unverified.md`.

Citation counts (total / h-index / i10, shown at the top of the Publications page)
come from OpenAlex — refresh them a few times a year:

```
python3 fetch_citations.py --dry-run
python3 fetch_citations.py
python3 build.py
```

Commit `publications.json` and `citations.json` after regenerating.

## Deploy

`build/` is a complete static site. Upload it to the web host:

```
rsync -avz --delete build/ user@host:/path/to/webroot/
```
